01 / 角色与记忆

支持角色 JSON、PNG 角色卡和人设 TXT。也可以直接粘贴 OVO 的人设与记忆。

世界书按分类管理，支持批量导入

02 / 模型设置

使用你自己的 OpenAI 兼容接口。填写提供商给出的 Base URL 和模型名称。

Key 保存在运行助手的设备上，保存后不会回显。角色资料和聊天上下文会发送给你配置的模型服务。

保存后可测试。只发送一条短测试消息，模型服务商可能按正常调用计费。

03 / 连接微信

微信 → 我 → 设置 → 插件 → 微信 ClawBot。获取二维码后扫码，并在微信确认连接。

下载二维码图片

同一部手机操作时，可以先截图，再从微信扫一扫的相册中选择。如果微信要求实时扫码，可用另一块屏幕展示。

微信没有返回扫码用户标识。先开启收取消息，再从微信发一条文字；确认下方标识属于你后绑定。

连接后，点击上方“开启自动回复”。目前支持私聊文字，以及微信提供的语音转写。没有转写时会提示已收到语音；照片可在「06 / 聊天体验」开启识别，文件与群聊暂不处理。微信登录失效后需要重新扫码。

04 / 连接 Telegram

验证并保存 Bot 后，点「打开 Telegram」或扫码，在聊天里点 Start。回到这里开启自动回复。

填写服务器能访问的 HTTP CONNECT 代理，例如 http://127.0.0.1:7890。「测试连通性」可以在填 Token 前使用。

密钥须与 Pages 的 RELAY_KEY 相同。BotFather Token 填在 Pages 的 TELEGRAM_BOT_TOKEN Secret 里。测试会检查服务器到 Pages、以及 Pages 到 Telegram 两段连接。

链接 10 分钟内有效。请用你自己的 Telegram 账号打开并点 Start。

05 / 共享长期记忆

在微信或 Telegram 单独发「记住：你想保存的内容」，就会保存到这里。两边聊到相关话题时都可以参考。

06 / 聊天体验

时间感知已启用。助手按北京时间参考消息时间与对话间隔。

需要支持图片输入的模型。开启后，照片会交给已配置的模型服务，来信只在本轮处理照片，历史记录保留文字标记。Telegram Pages 中转请先升级到 v4，微信加密照片需要安装包内说明所列的解密依赖。

开启后，回复时会参考另一边最近 24 小时内已完成的对话。

在允许的时段随机发来一条消息，偶尔写一封短来信。刚聊完时会跳过。

时段使用北京时间。开始与结束相同表示全天可收。暂停 Telegram 自动回复时，主动来信也会暂停。
